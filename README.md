# ドパガキ魔王 召魂の儀（開発中・ガチャ試遊版）

開発中のブラウザゲーム『怒破我喜さま／ドパガキ魔王』から、**ガチャ（召魂の儀）の部分だけ**を切り出した試遊版です。
インストールなしで、ブラウザから何度でも召魂できます。

**▶ 遊ぶ：https://keda-commits.github.io/dopagaki-maou-gacha-demo/**

## これは何か
- 魔王が鎖を引き、魂晶を投げ込んで魔族を召喚する「召魂の儀」を、何度でも体験できます。
- **無制限試遊モード**：魂晶は「∞」。所持数で止まらず、減りもしません。回数の上限・回復待ち・課金・広告・アカウント登録はありません。
- 開発中のゲームの試遊版です。**登場する魔族・レア度・確率・台詞・演出はすべて試作中のもので、正式な仕様ではありません。**
- 本編では「戦闘に勝ったあと、魔王が自分から召魂を始め、プレイヤーはそれを止めることだけができる」仕組みです。この試遊版には戦闘がないため、召魂を始めるボタンを用意しています（本編の仕様ではありません）。

## 遊び方
| 操作 | PC | スマートフォン |
|---|---|---|
| はじめる | クリック／Space | タップ |
| 単発召魂（もう一回） | Space／ボタン | ボタン |
| 十連召魂 | Enter／ボタン | ボタン |
| 早送り | 演出中に画面をクリック／Space を押している間 | 演出中に画面をタップ |
| スキップ | S／ボタン | ボタン |
| 魔王軍の名簿 | R／ボタン（Esc で閉じる） | ボタン |
| 音量・ミュート | 下のつまみ・ボタン | 同じ |

## 抽選（試作値）
| レア度 | 確率 |
|---|---|
| N（下級魔族） | 52% |
| R（中級魔族） | 30% |
| SR（上級魔族） | 13% |
| SSR（魔将） | 4.5% |
| UR（災厄級） | 0.5% |

- 十連召魂では、SR 以上が 1 体もいなければ最後の 1 体が SR 以上になります（保証）。
- SSR 以上が出ないまま 90 回目になると、その回は SSR になります（天井）。名簿で「天井まで あと何回」を確認できます。
- 無制限でも確率は変えていません。同じ魔族も通常どおり出ます（自動で融合・強化はしません）。

## 記録
- 名簿（獲得した魔族・レア度・所持数・初めて引いたか）、累計の召魂回数、レア度ごとの獲得数、天井までの残りを、**このブラウザの localStorage にだけ**保存します。外部への送信はありません。
- 名簿の「記録をリセット」で消せます（確認があります）。
